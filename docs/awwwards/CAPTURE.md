# Capture Specification

Target capture:
- Desktop viewport: 1440 x 900
- Mobile viewport: 390 x 844
- Public EN routes: /, /portfolio, /services, /credentials, /contact, /studio
- Public PT routes: /pt, /pt/portfolio, /pt/services, /pt/credentials, /pt/contact, /pt/studio

The recording workflow targets a 30–60 second continuous walkthrough and enables Playwright video capture. Screenshot files are written as CI artifacts and are not committed to the repository automatically.
