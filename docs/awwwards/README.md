# Awwwards Submission Package

This directory contains the machine-readable and human-readable material prepared for the final Awwwards submission.

## Included

- Technical sheet
- Credits
- Developer Award note
- Capture specification
- Final Lighthouse output, when the Phase 15 security/performance workflow completes
- Desktop/mobile screenshots and 30–60 second Playwright recording, produced as CI artifacts

## Evidence rule

Only generated CI artifacts and measured reports are treated as final evidence. No invented performance score, audience statistic, award, client metric or credit is included.
